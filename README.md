# Tampico · Climb the Rare

A rarity trivia game: every prompt has dozens of right answers, and the rarer yours is, the higher you climb up 26 real mountains.

**Play:** open the GitHub Pages link for this repository.

- `index.html` is the whole game (version 1.16).
- `shim.js` connects the shared features (leaderboard, crews, ghosts, prompts, duels, bug reports) to Supabase.
- `words.txt` is the dictionary used by word prompts.
- `version.json` tells open games when a newer version is out.
